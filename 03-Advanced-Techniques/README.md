# 03 — Advanced Techniques

Explore multi-step and system-level patterns. These methods introduce additional complexity and should be justified by measurable improvements.

## Planned lessons

- Prompt chaining and decomposition
- Tree-search-style reasoning patterns
- Retrieval-augmented generation (RAG)
- ReAct-style reasoning and tool use
- Self-consistency and sampling
- Meta-prompting
- Multimodal prompting
- Agentic workflows
- Prompt injection and defensive design

**Important:** A prompt is not a security boundary. Tool permissions, data access, validation, and execution controls must be enforced by the application.
