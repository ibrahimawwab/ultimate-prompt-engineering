# Contributing

Thank you for helping improve Ultimate Prompt Engineering. Contributions should make the material more accurate, useful, accessible, and responsible.

## Before you start

1. Read the [README](README.md), [Code of Conduct](CODE_OF_CONDUCT.md), and [Security Policy](SECURITY.md).
2. Search existing issues and pull requests to avoid duplicate work.
3. For substantial changes, open an issue first to agree on scope.
4. Do not include secrets, private data, personal information, or material you do not have permission to publish.

## Good contributions

- Correct factual errors and broken links.
- Improve explanations without overstating model capabilities.
- Add examples that are reproducible, safe, and clearly label assumptions.
- Add prompts with variables, intended use, sample input, expected output characteristics, and limitations.
- Improve accessibility, navigation, translations, and exercises.
- Cite primary documentation or original research for technical claims.

## Pull request process

1. Create a focused branch from `main`.
2. Make a small, coherent change; avoid unrelated formatting churn.
3. Use descriptive Markdown headings and relative links where appropriate.
4. Run the Markdown checks locally if possible and inspect rendered links.
5. Open a pull request describing the problem, approach, affected files, and validation performed.
6. Disclose any AI assistance used to generate substantial content and verify all generated claims yourself.

A maintainer may request revisions, sources, or test cases. Passing automated checks does not establish factual correctness.

## Content quality checklist

- [ ] Claims are accurate, qualified, and supported where necessary.
- [ ] Provider- or model-specific behavior is labeled as such.
- [ ] Examples do not expose secrets or use real sensitive data.
- [ ] Limitations, failure modes, and safety implications are included.
- [ ] Links resolve and point to appropriate sources.
- [ ] The contribution does not copy unlicensed material.

## Style

Use plain, precise English. Define specialized terms on first use. Prefer concise examples and explain why they work. Avoid fabricated benchmarks, fake testimonials, guaranteed outcomes, and unsupported claims of superiority.
