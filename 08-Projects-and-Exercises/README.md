# 08 — Projects and Exercises

Practice prompt design with progressively more demanding tasks. Exercises should have clear objectives, constraints, evaluation criteria, and reflection questions. Solutions should explain trade-offs rather than present one wording as universally correct.

## Intermediate

- [Prompt Evaluation Lab](01-Intermediate-Prompt-Evaluation-Lab.md) — compare two ticket-classification prompts using synthetic cases, JSON validation, and a predefined rubric.

## Advanced

- [Evidence-Grounded Research Synthesis](02-Advanced-Case-Study-Evidence-Synthesis.md) — build a source inventory, observation ledger, claim-evidence matrix, and reviewable evidence brief.
