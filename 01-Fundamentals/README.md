## Learning outcomes

After completing this section, you should be able to:

- Define prompt engineering and explain its role in an AI workflow.
- Describe tokens, context windows, and high-level LLM generation.
- Identify task, context, constraints, output format, and evaluation criteria in a prompt.
- Select a prompt pattern based on the task.
- Separate instructions from source material and treat untrusted content carefully.
- Test outputs against explicit criteria and identify uncertainty.

## Practical exercise

Start with a vague request such as "Analyze this feedback." Rewrite it with a clear task, audience, relevant context, constraints, output format, and a rule for missing information. Then evaluate the output against at least three criteria.

See [Beginner Example 1: Prompt Anatomy](../examples/beginner/01-prompt-anatomy.md) for a worked example.

## Completion standard

You have completed this section when you can independently design a prompt for a bounded task, explain why each component is present, and identify what must be verified outside the model.
