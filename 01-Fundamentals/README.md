## Learning outcomes

After this section, you should be able to define prompt engineering, identify the main parts of a prompt, explain why model outputs are probabilistic, and recognize the limits of instructions alone.

**Practice:** Take a vague request and rewrite it with a clear task, relevant context, constraints, and a verifiable output format.
