# AI and Prompt Engineering Glossary

Concise definitions for terms used in this guide. Definitions are introductory; implementation details can vary by model and provider.

- **Agentic workflow:** A process in which a model can select or sequence actions, often using tools, toward a goal. The application must constrain permissions and validate actions.
- **Attention:** A mechanism used in transformer models to combine information from different positions in a sequence.
- **Context window:** The amount of input and generated content a model can process in one interaction, subject to the model's limits.
- **Few-shot prompting:** Providing examples in the prompt to demonstrate a desired task or output pattern.
- **Large language model (LLM):** A model trained to process and generate language-like sequences, commonly using token prediction objectives.
- **Multimodal model:** A model that can process or generate more than one modality, such as text, images, audio, or video.
- **Prompt:** The input supplied to a model, including instructions, context, examples, and sometimes data or tool results.
- **Prompt injection:** An attempt to influence a model by placing malicious or conflicting instructions in content the model processes.
- **Prompt engineering:** The practice of designing and evaluating model inputs and surrounding workflows to improve task performance.
- **Retrieval-augmented generation (RAG):** A system pattern that retrieves relevant external information and supplies it as context for generation.
- **Sampling:** A method for selecting generated tokens from a model's output distribution.
- **Structured output:** A response constrained to a defined format, such as JSON or a schema. Format constraints do not by themselves guarantee semantic correctness.
- **Token:** A unit used by a model's tokenizer to represent text or other input. Tokens are not necessarily words or characters.
- **Zero-shot prompting:** Asking a model to perform a task without supplying task-specific examples in the prompt.
