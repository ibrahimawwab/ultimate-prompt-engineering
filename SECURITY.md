# Security Policy

## Scope

This repository is primarily educational documentation and prompt examples. It is not itself an AI service, hosted application, or security boundary. Examples involving tools, agents, retrieval, or external systems may introduce risks when implemented.

## Supported versions

The latest content on the default branch is the only actively maintained version of this educational material.

## Reporting a vulnerability

If you identify a security issue in repository infrastructure, workflow configuration, or an example that could expose users to harm, please do not publish exploit details or sensitive data in a public issue. Contact the maintainer privately through the contact information on the GitHub profile. Include:

- A concise description and affected file or workflow.
- Reproduction steps using non-sensitive test data.
- Potential impact and any suggested mitigation.

Allow reasonable time for investigation and remediation before public disclosure. Do not access systems or data without authorization.

## Safe use of examples

- Never paste API keys, passwords, tokens, or private records into public prompts or issues.
- Treat retrieved documents, tool outputs, and user-supplied content as untrusted input.
- Apply least privilege, input validation, output validation, and human approval to consequential actions.
- Do not rely on prompt instructions as the sole defense against prompt injection or unauthorized tool use.
- Test agent workflows in isolated environments before connecting real accounts or data.
