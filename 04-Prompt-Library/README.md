# 04 — Prompt Library

A curated collection of reusable prompts. Entries should be starting points, not claims that a prompt works identically across every model.

## Categories

- ChatGPT
- Claude
- Gemini
- Coding
- Research
- Business
- Education
- Marketing
- Data analysis
- Productivity

## Entry standard

Each published prompt should include purpose, difficulty, when to use it, copy-ready text, variables, a sample input, expected output characteristics, adaptation tips, and limitations or safety notes.

The library will grow toward at least 50 reviewed prompts. Entries will be added only when they meet this standard.
