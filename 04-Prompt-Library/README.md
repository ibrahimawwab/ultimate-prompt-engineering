## How to use an entry

1. Choose a prompt that matches the task and risk level.
2. Replace each `{{VARIABLE}}` with relevant, verified context. Remove fields that do not apply.
3. State constraints, audience, and the output you need.
4. Review the result against the expected-output description and verify important claims.
5. Adapt and test the prompt with representative inputs before relying on it in a workflow.

## Entry standard

Every entry includes:
- Purpose, difficulty, and recommended use.
- A copy-ready prompt with named variables.
- An example input and expected-output characteristics.
- Adaptation guidance.
- Limitations and safety considerations.

## Review and responsible use

The collection is a practical starting library, not a claim that all 50 prompts have been empirically benchmarked across models. Prompt behavior varies by model, provider, configuration, context, and connected tools. Test prompts on representative cases and retain failure examples when evaluating changes.

For consequential work, verify facts against authoritative sources and use qualified human review. Medical and scientific prompts are not diagnostic or treatment tools. Cybersecurity prompts are for authorized defensive work only. Agent prompts do not enforce access control: permissions, validation, approval gates, and audit controls must be implemented in the application and tool layer.
