# 06 — Frameworks and Templates

Reusable structures help make prompts easier to inspect, adapt, and maintain. They are checklists, not magic formulas.

## Planned resources

- Universal prompt template
- Role–task–context–format framework

A good template should make required inputs and constraints explicit while leaving room for task-specific judgment.
