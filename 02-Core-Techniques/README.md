# 02 — Core Techniques

Learn widely used prompting patterns and understand when each is useful. No technique is universally best; choose based on task requirements and evaluate results.

## Planned lessons

- Zero-shot prompting
- Few-shot prompting
- Asking for concise explanations and verifiable intermediate results
- Role and persona framing
- Instructional and contextual prompting
- Structured-output prompting

Each lesson will include a definition, mechanism, worked examples, suitable use cases, failure modes, and model-dependent caveats.
